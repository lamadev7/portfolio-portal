drayOS is PortPro's logistics TMS. I've worked on it since June 2022, owning features end to end: data models and Node services on MongoDB and Sequelize, through to the TypeScript React screens.

## What I built

- Map surfaces with Mapbox GL (WebGL) and React Leaflet that stay smooth at production data volumes.
- Memory cleanup for long-running map sessions.
- Streaming bulk upload for large freight imports.
- A reusable component design system that cut new-screen lead time by about 40%.
- Real-time updates over Socket.io and Pusher, deployed on AWS with CI/CD.

## Agents

I'm now building an orchestrator AI agent that manages and monitors the platform's other agents, including the dispatcher, billing and customer-service sub-agents.
