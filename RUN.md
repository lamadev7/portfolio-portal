# Parbat Lama — Portfolio V4 (Two Trails on /)

```bash
pnpm install     # or: npm install
pnpm dev         # or: npm run dev  → http://localhost:3000
```

Production:

```bash
pnpm build && pnpm start
```

- `/`          Two Trails — 3D story (scroll / drag / ← → to walk · M = full map · Esc = close · click "Walk the Road" to start sound)
- `/classic`   classic portfolio (V3) · `/journey` redirects to `/`

Requires Node 18.17+ (Node 20 recommended).
